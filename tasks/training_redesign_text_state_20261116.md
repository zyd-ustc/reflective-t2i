# 文本条件噪声态编辑：训练重构建议

日期：2026-11-16。状态：研究与实现建议；未修改训练实现、配置或远端作业。

## 目标与选择

最终编辑器只读当前噪声态、时间和反馈文本，不新增源图、预览图、目标图的图像条件。训练目标是执行反馈指令，并产出可继续生成的状态；未编辑区域的像素保真不再是主要目标。

推荐：**高信噪比单步编辑教师 → 目标时间的单步蒸馏 → 原生 T2I 状态上的多轮反馈训练**。先不学习 K=8 的内部编辑 ODE，也不同时训练独立尾段。一次反馈的一次状态更新，与多轮反馈是两个不同的循环。

本建议是项目优化方案，不作方法新颖性主张。核心假设：先分离编辑语义学习与噪声鲁棒性学习，比直接在 t=0.36 上学习全图像素精确位移及八步积分更省训练成本。这个假设尚未验证。

## 当前代码的实际含义

- `train.py::_field_update`：从人工直线桥 q_s=(1-s)a_t+s b_t 采样，监督常量速度 b_t-a_t。它是构造的训练路径，不是原生生成轨迹，也不是经验证的最佳编辑轨迹。
- `train.py::_rollout_step_update`：无梯度走 k 步，当前一步预测剩余终点 q_k+(1-s_k)u，监督 b_t。它能学习纠偏，不是必须等编辑器完美才可训练；但弱编辑器会造成大量无效前缀计算。s=0 样本仍可提供初始学习信号。
- `train.py::_rollout_terminal_update`：K 步完整反传，监督 q_K。当前 editor Stage 2 配置混合 60% rollout_step、10% rollout_terminal、30% IFM（非 keep 样本）。
- `train.py::_tail_update`：独立 TailGenerator 学 q_K 到目标图的桥，编辑器不通过该损失更新。弱编辑器会把没完成的编辑转交给 tail。
- 配置只接受 `stage in (1,2)`。尾段配置也是 stage=2、component=tail；没有独立的 stage=3 配方。下面的新三阶段是重构后的命名。

当前 `state_velocity=t*(H_theta-H0(a_t))`。对同噪声图像对，要求 u=t*(T-S)，等价于要求 H_theta=T+[H0(a_t)-S]。监督值包含源图的冻结重建误差。全图像素 MSE 同时要求匹配编辑内容、背景和纹理；即使移除 keep 抽样，这个要求仍然存在。`valid` 是有效画布掩码，不是编辑区域。

## Monet：借鉴什么

本地 PDF 是 arXiv:2511.21395v2。其 SFT Stage 1 先让模型使用辅助图像；Stage 2 借助辅助图像与受控注意力学习有效 latent，并对齐关键观察 token；Stage 3 撤掉辅助图像，对齐已缓存的 latent。其关键是先得到对任务有用的监督，再训练受限输入模型，不是仅按数据难度排序。

本项目以较高 t 的源状态替代教师的辅助信息，教师和学生均无额外图像前缀。较高 t 表示噪声更少，仅降低识别源状态的难度；不等于结构编辑必然更容易。先验证教师是否真正学会编辑。

不直接复制 Monet 的全层隐藏状态对齐：不同 t 的表示还包含不同噪声。优先蒸馏经过任务验证的输出位移及编辑结果，不让学生复制教师的噪声表征。

## 统一接口与参数化

S、T 为源图、目标图；epsilon 含原生噪声尺度。t=0 为纯噪声，t=1 为干净图。

```
a_t = t*S + (1-t)*epsilon
d_theta = D_theta(a_t, t, e)
q = a_t + t*d_theta
```

D 输出按 t 归一化的编辑位移，理想配对标签为 T-S。接口不读 S、T、epsilon；这些量仅用于构造训练样本和损失。原生 T2I 状态也可直接进入该接口，无须知道其 epsilon。

实现方向：保留原生 GEN 主干、rank-64 LoRA、文本前缀，增加独立的可训练位移输出头，零输出初始化；不使用冻结原生 clean head 来承担新的位移读出任务。原生 T2I 输出头保留。第一版不需要编辑进度 s，也不调用 H0 来定义速度。新头在初始化时会先获得梯度，主干适配随后获得梯度。

这是输出接口变更，不是旧检查点的等价重命名。旧检查点仅可作对照；若迁移 adapter，必须明确不迁移旧输出语义。新路线首轮使用相同原生初始化以便比较。

## 新 Stage 1：先学会清晰状态上的单步编辑

1. 从现有训练集选约 20k–50k 可靠图像对，按 add/remove/move/attr 平衡，按 source_family 隔离验证。先以单一动作指令为主，不引入新数据集。
2. 使用较高 t（初始候选 0.65、0.80），仅在 a_t 输入处监督单次编辑。不从已混入目标的 q_s 随机位置启动。
3. 训练 LoRA 与位移头。无需在线 H0、学生前缀 rollout 或多步反传。
4. 在留出样本检查编辑动作、目标对象、数量/关系/属性，以及基本图像可用性。只降训练 loss 不进入下一阶段。

这些 t 是待验证的课程设置，不是此前诊断已证明的最优点。若教师在高信噪比条件仍不能完成动作，先解决标签、损失与读出能力，不提前做噪声蒸馏。

### 损失：把精确像素目标降为辅助监督

对合成线性噪声样本，训练时可构造 X_hat=S+d_theta。这仅用于计算损失，不把 S 输入网络。

- 廉价主干监督：编辑相关区域的多尺度、低频 Huber 位移损失。对 add/remove/move，区域应覆盖源位置、目标位置和必要上下文。任务为全局修改时覆盖全图。对小对象使用局部尺度，不能仅缩到全图 64×64。
- 不再使用全图高频像素重建作为主损失，不使用源图背景保真损失。区域外可用很弱的位移能量正则限制失控更新；它不是背景保持验收项。
- 任务语义：数量、对象、属性和关系单独验证。低频/区域位移损失仍是代理目标，不能保证指令执行。后续可在少量样本加冻结观察器的结构化答案损失；观察器读 X_hat 并回答目标数量/关系，梯度穿过输入回到编辑器。
- 当前数据加载器没有编辑区域字段，现有 VLM 评估也不是可直接反传的损失。第一版需要补齐训练用区域标注/权重；冻结观察器的可微路径是独立实现项，不能把 API 判断分数当成可微 loss。已有可靠目标框/掩码优先复用；原始图像差分不能直接当作语义编辑掩码。

任务语义项昂贵，不应默认给所有训练步增加一遍完整 VLM 前后向。第一轮用已有离线评估筛选教师结果，判断廉价损失是否足够；不足时才补充稀疏的可微语义监督。

## 新 Stage 2：将成功教师蒸馏到 t=0.36

教师在 a_h=t_h*S+(1-t_h)*epsilon 上产生 d_T，学生在 a_l=t_l*S+(1-t_l)*epsilon 上学习，配对使用相同 S、e、epsilon。t_l 可从 0.50 过渡到 0.36，并保留少量高 t 训练样本。

缓存并仅接收通过动作和图像可用性检查的教师预测。学生先从教师权重初始化；教师冻结。比较的是归一化位移 d，不是 u=t*d 或不同噪声尺度的 q。学生保留真实图像对的任务区域监督，避免只复制教师误差。

```
L_stage2 = L_edit(student, paired target)
         + lambda_distill * L_edit(student displacement, stopgrad(teacher displacement))
```

不让学生自己走八步来生产其主要训练输入。缓存绑定样本、教师版本、教师 t 与噪声 seed；不得用不相配的噪声预测冒充逐样本蒸馏标签。

蒸馏增加了教师训练、推理、筛选和缓存成本。它的价值必须超过“同样先高 t 后低 t、但只用真实配对监督”的简单课程基线。如果 teacher 只复述 T-S 标签而没有带来更易学的任务输出，直接课程即可，删除蒸馏阶段的额外计算。

## 新 Stage 3：原生 T2I 状态与多轮反馈

目标不再是八步内部积分稳定，而是学生在原生生成状态上收到反馈后能修正结果。

1. 在训练侧原有 prompt/source_family 上缓存真实 T2I 的 t=0.36 状态；原始生成 prompt 与反馈文本应与最终部署一致。目标图派生 caption 不作为学生额外条件。
2. 离线构造候选纠正状态。可把真实状态沿原生生成推进到较高 t，让教师产生归一化编辑位移，再将其映射回初始状态作为候选：q_candidate=z_0.36+0.36*d_T。
3. 上述跨时间映射不是精确轨迹传输。只有经过固定原生尾段续生成、确实完成反馈动作且图像可用的候选才成为训练目标。报告候选接受率与分桶覆盖，避免只留下容易的 remove 样本。
4. 学生对原始真实状态学习单步达到成功候选，混合 Stage 2 样本回放。候选不通过则不加入缓存，不以 target caption 兜底替它完成编辑。
5. 先形成成功的单轮数据，再收集两轮和三轮：每轮针对当前预览重新给反馈，而不是把同一个相对指令（如“再删除一个”）重复执行多次。可用已核验的结构化反馈模板隔离诊断器误差，再评估完整诊断闭环。

学生对这些真实状态的 loss 使用 (q_student-q_teacher)/t，而不能再用只有合成线性噪声才成立的 S+d 解释图像。最终任务判断必须读取实际续生成结果。

原生尾段先固定，同一对照共用策略。原始 T2I prompt 保持不变；若以后允许改写 prompt，应给所有基线相同条件并单列其贡献。只有编辑动作已经可见、续生成却系统性损坏结果时，才单独讨论 tail 适配。

## 最小验证与成本纪律

先做三条小预算线，不重启 1500 万数据训练：

| 线 | 用途 |
|---|---|
| A：旧参数化 + 旧损失，t=0.36 | 小数据上的原配方对照 |
| B：单步位移 + 任务区域损失 + 高到低 t 课程 | 检验简化本身是否有效 |
| C：B + 成功教师蒸馏 | 检验蒸馏是否值得额外成本 |

首轮三线只是路线筛选，不能把 A→B 的收益单独归因给某一个改动。若需要机制归因，再拆参数化/损失/课程，不先铺满消融矩阵。

- 使用相同训练家族、验证家族、主干、分辨率和 LoRA rank；同时报告训练曝光量与总设备小时。C 的教师训练、缓存和筛选都计成本。
- 与 A 的比较既要包含同样训练预算，也要包含相同推理计算的报告；单步与 K=8 是不同成本点，不能只报各自最有利的数字。
- 主指标改成编辑成功与原始目标 prompt 对齐，分别报告 add/remove/move/attr、基本图像质量及总时延。背景 L1 只作诊断，不再决定通过。旧 StrictPass/overall_pass 若含 preserve_pass，需另命名新版指标，不能混用历史曲线。
- 多轮报告每轮原始任务符合率、已纠正属性是否又被破坏，以及比上一轮改善的比例；“不要求背景像素保持”不等于可以忘掉原始任务。
- 最终比较必须保留未编辑状态 + 相同原始 prompt/尾段/反馈预算的基线，证明收益来自状态编辑。

## 实现边界

主要改动位置：`model.py` 的编辑输出头与接口；`train.py` 的单步监督和教师缓存采样；`loss.py` 的任务区域多尺度损失；`data.py` 的区域标注及教师记录；`config.py` 的多时间课程与新协议；`field.py`/推理调用方的单步更新。旧配方保留，不静默改变旧检查点含义。

先实现与验证 B，再决定是否投入 C 和真实状态候选采集。方案中的损失、教师、缓存及真实状态迁移都尚未实现。
